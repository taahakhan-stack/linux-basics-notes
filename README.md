# Linux Basics Notes 🐧

This repository is where I keep the Linux commands and concepts I'm learning during my DevOps journey.

When I'm practising something new, I like to save useful commands and notes here so I can come back to them later instead of having to search for everything again. I'm still learning, so I'll keep updating this repository as I gain more experience.

## What I'm learning

- **Linux commands** — getting comfortable with the terminal and learning how to work with files and directories.
- **File permissions** — understanding who can read, write, or execute files.
- **Users and groups** — learning how Linux accounts and permissions work.
- **Processes** — checking what's running on the system and how to manage it.
- **Networking** — practising basic networking commands and understanding connectivity.
- **Vagrant** — learning commands for working with virtual development environments.
